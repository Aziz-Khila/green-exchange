# Green Exchange - E-Commerce Marketplace Platform

Developed a fullstack web application for trading recyclable waste materials between buyers and sellers. Buyers browse listings, add items to cart, and place orders. Sellers create listings with images, manage orders, and track revenue. Admin approves order completions, manages users and listings, configures commission rates, and oversees platform operations. Includes shopping cart, wishlist, order management with admin approval workflow, dynamic commission system, PDF invoice generation, notifications, multi-language support (EN/FR/AR), and role-based access control. Built with PHP (PDO), MySQL/SQLite, HTML5, CSS3, and JavaScript, deployed on InfinityFree.
